# CLIQuotaMonitor 需求理解

更新时间：2026-09-20

## 目标

在 Windows 10/11 上提供一个常驻桌面悬浮窗，统一展示 Codex、Grok、Antigravity CLI 的动态额度、剩余比例/数值和重置时间。查询必须启动隔离的 CLI 子进程，不注入用户正在使用的会话，不保存账号密码或远程上传额度数据。

## V1 范围

- WPF 无边框透明悬浮窗，支持拖动、锁定位置、置顶、透明度、紧凑/详细布局。
- 系统托盘：显示/隐藏、全部刷新、设置、退出；关闭窗口默认隐藏到托盘。
- Codex `/status`、Grok `/usage`、Antigravity `/usage` 的 Provider + Parser 适配器。
- 自动发现 PATH、npm/AppData、Program Files 中的 CLI，也允许设置绝对路径。
- Auto/Command/PTY 查询路由；Command 参数可在设置中覆盖内置 PTY 查询。
- Windows ConPTY 交互式查询，默认 10 秒超时，查询进程独立终止。
- 动态额度周期解析，不硬编码 5 小时或 Weekly；支持相对/绝对 Reset 时间和 Grok Session token 展示。
- 自动刷新、手动刷新、同一 Provider 单飞并发控制、成功结果 JSON 缓存和失败时的陈旧数据回退。
- 可选工作时间限制：按周一至周日选择自动刷新的日期，并设置每日开始/结束时间；手动刷新不受限制。
- 可见 Provider 和额度周期控制、低额度托盘提醒、静默时间、随 Windows 启动。
- 本地配置与缓存位于 `%LOCALAPPDATA%\\CLIQuotaMonitor`。

## 暂不纳入 V1

- 多账号切换、额度历史图表、插件下载/热更新。
- JSONPath/Regex/PowerShell/HTTP/Local File 等通用自定义解析器。
- 鼠标穿透、贴边吸附、Mica/Acrylic、多主题和完整设置分类页。

## 关键约束

1. Provider 只输出统一 `QuotaSnapshot`，UI 不读取 CLI 原始输出。
2. 额度名称由解析结果动态发现，解析失败不能显示为 0%。
3. 失败刷新保留上次成功值，并显示“缓存/刷新失败”状态。
4. 错误消息和日志边界必须脱敏；不保存完整 CLI 输出。
5. 查询超时只能终止查询子进程，不能影响用户已有 CLI 进程。
