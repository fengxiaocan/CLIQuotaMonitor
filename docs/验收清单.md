## 手动验收

- [ ] 启动后出现透明悬浮窗，Codex/Grok/Antigravity 未安装时分别显示“未安装”。
- [ ] 拖动、锁定位置、置顶、透明度、紧凑/详细模式可用。
- [ ] 双击、刷新按钮、右键“刷新全部”和托盘“刷新全部”均可触发查询。
- [ ] 关闭窗口进入托盘，托盘可重新显示和退出。
- [ ] 设置绝对 CLI 路径和 Command 参数后能保存并在下一次刷新使用。
- [ ] 可启用工作时间限制，选择周一至周日任意组合并设置开始/结束时间。
- [ ] 工作时间外自动刷新暂停，进入工作时间后恢复；手动刷新仍可执行。
- [ ] Provider 与动态额度周期可在右键菜单中隐藏/恢复。
- [ ] 额度低于阈值时托盘提醒，静默时间内不弹出。
- [ ] 打开“随 Windows 启动”后注册当前用户启动项；带 `--startup` 启动时隐藏浮窗但保留托盘。
- [ ] 查询失败时保留最近成功额度，并显示陈旧/失败状态，不显示伪造的 0%。
